## 背景・課題・解決されること
　私たちが心から欲しいもの、それは作業と休息のバランスである。
私たちエンジニアは、仕事柄特に、作業を頑張れば頑張るほど、決してデジタルデバイスと離れることはできない。反対に、デジタルデトックスに力を入れようとすると、作業に身が入らなくなってしまうだろう。
そこで私たちは、スマホをフィルムカメラに変えるアプリ「Devit」を提案する。　
　コミットをすることで得られるフィルムで撮影を行うことができる。しかし、現像をするには1時間もの間、画面で待機する必要がある。
現像後は3種類のオリジナルフィルムに沿った加工が施され、次のコミットへのやる気向上を促すことができる。

### アイデア面
テーマに沿って、アイデアを組み合わせ、作業と休養という相容れないもののバランスを手助けするものができた。

### デザイン面
画面を横に統一し、撮影画面を画面一部に限定したり、シャッターが閉じる演出等を実装し、スマホをカメラに見立てたUI設計にしている。あえてアナログ感を残し、アプリっぽくないのもポイントだ。

### その他
フィルム加工そのものにも力を入れ、新しく、独特でありながらどこか懐かしいデザインに仕上がることができた。
