## 背景・課題・解決されること
　私たちが心から欲しいもの、それは作業と休息のバランスである。
私たちエンジニアは、仕事柄特に、作業を頑張れば頑張るほど、決してデジタルデバイスと離れることはできない。反対に、デジタルデトックスに力を入れようとすると、作業に身が入らなくなってしまうだろう。
そこで私たちは、スマホをフィルムカメラに変えるアプリ「Devit」を提案する。　
　コミットをすることで得られるフィルムで撮影を行うことができる。しかし、現像をするには1時間もの間、画面で待機する必要がある。
現像後は3種類のオリジナルフィルムに沿った加工が施され、次のコミットへのやる気向上を促すことができる。

## 操作説明・デモ動画
[デモ動画はこちら](https://www.youtube.com/watch?v=fbzGp0XJGq8)
<!-- 開発したプロダクトの操作説明について入力してください。また、操作説明デモ動画があれば、埋め込みやリンクを記載してください -->

1. GitHub連携とログイン
アプリを起動後、GitHubのユーザー名と個人アクセストークン (PAT) を入力してログインします。

GitHub username: あなたのユーザー名を入力します。

Personal Access Token (PAT): GitHubから発行したトークンを入力します。

Git Email (任意): 設定すると、コミットの検出精度が向上します。

2. フィルムの入手（コミットチェック）
ホーム画面の「コミットチェック」ボタンをタップします。

前回のチェック以降にGitHubへプッシュされたコミット数に応じて、ランダムにフィルムが付与されます。

獲得したフィルムは画面上部のインベントリに表示されます。

3. 写真撮影
フィルム選択: 下部のスロットから使用するフィルム（Cinema, Vivid, Retro）を選択します。

撮影: 右側のシャッターボタンを押すと、フィルムを1本消費して撮影します。

カメラ操作: ズーム調整やフラッシュの切り替えが可能です。

ジェスチャー: 画面を下にスワイプするとアルバムへ、上にスワイプすると暗室へ移動できます。

4. 暗室での現像（デジタルデトックス）
撮影した写真は「未現像」状態であり、そのままでは見ることができません。ホームの「暗室へ移動」ボタンから現像を行います。

現像開始: 「START DEVELOPING」をタップして現像を開始します。

待機時間: 現像には一定の待機時間が必要です。この間、作業の手を止めて休息しましょう。

現像完了: タイマーが終了すると現像が完了し、フィルム独自の加工が施された写真を確認できます。

5. アルバムでの閲覧
現像された写真はアルバム画面に保存されます。

コミットの成果として得られた「いい感じ」の写真をいつでも振り返ることができます。

### アイデア面
テーマに沿って、アイデアを組み合わせ、作業と休養という相容れないもののバランスを手助けするものができた。

### デザイン面
画面を横に統一し、撮影画面を画面一部に限定したり、シャッターが閉じる演出等を実装し、スマホをカメラに見立てたUI設計にしている。あえてアナログ感を残し、アプリっぽくないのもポイントだ。

### その他
フィルム加工そのものにも力を入れ、新しく、独特でありながらどこか懐かしいデザインに仕上がることができた。
